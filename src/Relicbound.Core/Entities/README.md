# Entities

The `Entity` type and its components: `Health`, `StatBlock`, `GridPosition`, `Statuses`, `Equipment`, `Abilities`, `TurnResources`, `Intent`.

> Composition, not inheritance. The player and a goblin are the same type and differ only by components. There is no `Character : Entity`.

See [`docs/CODING_STANDARDS.md`](../../../docs/CODING_STANDARDS.md) for the rules that govern this folder.
